## Uso de este archivo

Este archivo mantiene la lista de migraciones que **falta ejecutar** en cada ambiente. Cuando se agrega una migración nueva a `database/migrations/`, agregala aquí con:

- Ruta al archivo SQL
- Descripción corta de qué crea (tabla, columna, SP, etc.)
- Ambientes donde ya se aplicó y donde falta

Cuando la migración se ejecuta en todos los ambientes, se retira de esta lista y se anota en el log de decisiones del proyecto (`docs/00-README.md`).

## Recomendación futura

El proyecto **no usa Flyway ni Liquibase**. El tracking de migraciones aplicadas depende de mantener este archivo al día a mano — proceso frágil.

Alternativas a evaluar en Fase 1 o posterior:

1. **Tracking mínimo**: agregar tabla `_schema_migrations (filename, applied_at, applied_by)` — solo requiere que cada script SQL termine con un `INSERT INTO _schema_migrations`. Aditivo, cero riesgo.
2. **Flyway/Liquibase**: adoptar como estándar, con las 65 migraciones existentes como baseline. Requiere una migración inicial de setup pero después todo automatizado.
